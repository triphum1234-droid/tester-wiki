# Tester Wiki

เว็บบทความภาษาไทยสำหรับเรียนรู้ Software Testing ตั้งแต่พื้นฐานและการออกแบบกรณีทดสอบ ไปจนถึง API, SQL, automation, performance, accessibility, security และการทำงานร่วมกับทีม

## เปิดใช้งาน

โปรเจ็กต์นี้เป็น static web app ไม่มี backend หรือขั้นตอน build ให้เปิด `index.html` ในเว็บเบราว์เซอร์ได้โดยตรง

หน้าเว็บโหลด Tailwind CSS, Font Awesome และฟอนต์ Sarabun/Space Grotesk จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อให้รูปแบบและไอคอนแสดงครบ

## เนื้อหา

- `index.html` — หน้าเว็บและบทความทั้งหมด รวมเมนูค้นหา การนำทาง และแหล่งอ้างอิง

## การนำไปเผยแพร่

นำไฟล์ใน repository นี้ไปวางบน static hosting โดยใช้ `index.html` เป็นหน้าแรกได้ ไม่ต้องติดตั้ง package หรือ build ก่อนเผยแพร่ หากเว็บเปิดให้สาธารณะ ควรทบทวนเนื้อหาและการเปิดเผยข้อมูลให้เหมาะกับกลุ่มผู้อ่านก่อน

## แหล่งอ้างอิง

บทความที่อิงแนวทางหรือรายละเอียดเครื่องมือมีลิงก์ไปยังเอกสารของหน่วยงานและผู้พัฒนาอยู่ท้ายบทความที่เกี่ยวข้อง
