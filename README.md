# Tester Wiki

เว็บบทความภาษาไทยสำหรับเรียนรู้ Software Testing ตั้งแต่พื้นฐานและการออกแบบกรณีทดสอบ ไปจนถึง API, SQL, automation, performance, accessibility, security และการทำงานร่วมกับทีม พร้อมห้องฝึกทักษะจากสถานการณ์จำลองและคำอธิบายหลังตอบ

## เปิดใช้งาน

โปรเจ็กต์นี้เป็น static web app ไม่มี backend หรือขั้นตอน build ให้เปิด `index.html` ในเว็บเบราว์เซอร์ได้โดยตรง

หน้าเว็บโหลด Tailwind CSS, Font Awesome และฟอนต์ Sarabun/Space Grotesk จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อให้รูปแบบและไอคอนแสดงครบ

## เนื้อหา

- `index.html` — หน้าเว็บและบทความทั้งหมด รวมเมนูค้นหา การนำทาง แหล่งอ้างอิง และห้องฝึกทักษะ Tester แบบโต้ตอบ 22 โจทย์ ครอบคลุมการออกแบบการทดสอบ, API/HTTP, SQL, Test Data, Accessibility, Security, Performance, Automation และ CI/CD ความคืบหน้าบันทึกไว้ในเบราว์เซอร์ของผู้ใช้แต่ละคนโดยไม่ส่งไป backend

## การนำไปเผยแพร่

GitHub Pages เผยแพร่เว็บจาก branch `main` ที่โฟลเดอร์ราก โดยใช้ `index.html` เป็นหน้าแรก เมื่ออัปเดตไฟล์บน branch นี้ GitHub จะสร้างและเผยแพร่เว็บไซต์ให้อัตโนมัติ โปรเจ็กต์นี้ไม่มี backend หรือขั้นตอน build เพิ่มเติม

## แหล่งอ้างอิง

บทความที่อิงแนวทางหรือรายละเอียดเครื่องมือมีลิงก์ไปยังเอกสารของหน่วยงานและผู้พัฒนาอยู่ท้ายบทความที่เกี่ยวข้อง
